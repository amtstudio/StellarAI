# ============ 人工智能基础 ============
人工智能是计算机科学的一个重要分支，它致力于研究开发模拟人类智能的理论方法和技术。
人工智能的目标是让计算机具备感知、推理、学习和决策的能力。
人工智能的发展经历了符号主义、连接主义和深度学习三个主要阶段。
强人工智能指具备与人类同等智能的通用人工智能，弱人工智能则专注于特定任务。
人工智能技术正在改变医疗、教育、交通、金融等各个行业。
人工智能伦理关注AI系统的公平性、透明性、隐私保护和责任归属。
人工智能的未来发展方向包括通用人工智能、具身智能和神经符号系统。
人工智能系统需要大量的数据和算力支持才能发挥最大效能。

机器学习是人工智能的核心技术之一，通过算法让计算机从数据中学习规律。
机器学习分为监督学习、无监督学习和强化学习三大类。
监督学习使用带标签的数据训练模型，常用于分类和回归任务。
无监督学习从无标签数据中发现模式，典型方法包括聚类和降维。
强化学习通过试错和奖励机制训练智能体做出最优决策。
机器学习模型的性能取决于数据质量、特征工程和算法选择。
过拟合是机器学习中的常见问题，指模型在训练集上表现好但在测试集上表现差。
交叉验证是评估机器学习模型泛化能力的重要方法。
特征工程对传统机器学习模型的性能有决定性影响。
集成学习通过组合多个弱学习器构建强学习器，如随机森林和梯度提升树。

深度学习使用多层神经网络来处理复杂的模式识别问题。
深度学习是机器学习的一个子领域，基于人工神经网络的研究。
深度学习模型通过反向传播算法自动学习数据的层次化特征表示。
深度学习在图像识别、语音识别、自然语言处理等领域取得了突破性进展。
卷积神经网络擅长处理图像数据，循环神经网络擅长处理序列数据。
Transformer架构的出现彻底改变了自然语言处理领域的格局。
深度学习模型通常需要大量数据和计算资源进行训练。
深度学习模型的可解释性是一个重要的研究方向。
深度学习已经在计算机视觉、自然语言处理、语音识别等领域超越了传统方法。
残差连接和层归一化是训练深层神经网络的关键技术。

# ============ 神经网络基础 ============
神经网络是模仿生物神经网络结构和功能的数学模型。
神经网络的基本单元是神经元，它接收输入并产生输出。
激活函数为神经网络引入非线性，常用的有ReLU、Sigmoid和Tanh。
反向传播算法是训练神经网络最常用的方法，通过链式法则计算梯度。
梯度下降是优化神经网络参数的基本算法，包括批量、小批量和随机三种变体。
学习率是梯度下降中最重要的超参数，需要仔细调整。
过大的学习率会导致训练不稳定，过小的学习率会导致训练缓慢。
Dropout是一种正则化技术，通过随机丢弃神经元防止过拟合。
批归一化通过标准化每层的输入加速训练并提高稳定性。
权重初始化对神经网络的训练效果有重要影响，Xavier和He初始化是常用方法。

卷积神经网络通过卷积操作提取图像的局部特征。
池化层用于降低特征图的空间维度，减少参数数量。
CNN在图像分类、目标检测、语义分割等视觉任务中表现出色。
感受野是卷积神经网络中的重要概念，指神经元感知输入的区域大小。
经典的CNN架构包括LeNet、AlexNet、VGG、ResNet和EfficientNet。
ResNet通过残差连接解决了深层网络训练困难的问题。
Inception模块通过多尺度卷积并行提取特征。

循环神经网络专门处理序列数据，具有记忆能力。
长短期记忆网络通过门控机制解决了RNN的梯度消失问题。
GRU是LSTM的简化版本，性能相当但参数更少。
双向RNN同时利用过去和未来的信息处理序列。
Seq2Seq模型结合编码器和解码器处理序列到序列的任务。
注意力机制让模型能够关注输入序列中最重要的部分。
Transformer完全基于注意力机制，摒弃了循环结构。

# ============ Transformer与注意力 ============
Transformer架构是现代大模型的基础，采用自注意力机制处理序列数据。
Transformer由编码器和解码器组成，每个模块包含多头注意力和前馈网络。
自注意力机制让序列中的每个位置都能关注其他所有位置。
多头注意力并行地执行多个注意力计算，捕捉不同子空间的信息。
位置编码为Transformer提供序列的位置信息，分为绝对和相对位置编码。
RoPE旋转位置编码是一种相对位置编码方法，具有良好的外推性。
层归一化和残差连接是Transformer的重要组成部分。
Transformer在机器翻译、文本生成、图像处理等任务中表现优异。
Vision Transformer将Transformer架构应用于图像识别领域。
Swin Transformer通过滑动窗口机制提升了ViT的效率。

注意力机制让模型能够动态地关注输入的不同部分。
注意力的计算基于查询、键和值三个矩阵的相似度。
缩放点积注意力是最常用的注意力计算方法。
Softmax函数将注意力分数归一化为概率分布。
注意力机制的计算复杂度与序列长度的平方成正比。
线性注意力和稀疏注意力是降低复杂度的常用方法。
FlashAttention通过内存优化显著加速了注意力计算。
交叉注意力用于融合不同模态的信息，如图像和文本。

# ============ 大语言模型 ============
大语言模型通过海量文本数据训练，能够生成流畅的自然语言文本。
大语言模型的参数规模从数百万到数千亿不等。
大语言模型展现出了涌现能力，即模型规模增大后出现的新能力。
GPT系列模型采用解码器架构，通过预测下一个token进行训练。
BERT采用编码器架构，通过掩码语言模型任务进行预训练。
T5模型将所有任务统一为文本到文本的格式。
指令微调让大模型更好地理解和执行人类的指令。
人类反馈强化学习（RLHF）使大模型的行为更符合人类期望。
思维链提示让大模型通过中间推理步骤解决复杂问题。
上下文学习是大语言模型的重要能力，无需微调即可学习新任务。

预训练是大语言模型训练的第一阶段，使用大规模无标注文本。
预训练任务包括掩码语言模型和因果语言模型两种。
预训练数据的质量和多样性对模型性能有重要影响。
清洗和去重是预处理训练数据的关键步骤。
分词器将文本转换为模型可以处理的token序列。
BPE分词器通过合并频繁出现的字符对构建词表。
WordPiece分词器在BERT等模型中广泛使用。
SentencePiece是一种语言无关的分词方法。
词表大小影响模型的参数量和性能，通常在3万到20万之间。

微调是在预训练模型的基础上适应特定任务的过程。
全参数微调更新模型的所有参数，效果最好但成本高。
LoRA通过低秩矩阵分解实现参数高效微调。
Prefix Tuning通过优化可学习的前缀实现微调。
Prompt Tuning仅优化输入的提示向量。
指令微调使用指令格式的数据训练模型遵循指令。
RLHF通过人类偏好数据训练奖励模型并优化策略。
DPO是一种简化的RLHF方法，直接优化偏好数据。

自然语言处理让计算机能够理解和生成人类语言。
自然语言处理包括自然语言理解和自然语言生成两大方向。
分词是中文自然语言处理的基础任务。
词性标注为每个词标注其语法类别。
命名实体识别从文本中识别人名、地名、机构名等实体。
句法分析分析句子的语法结构。
语义理解是自然语言处理的核心挑战。
机器翻译将一种语言的文本翻译成另一种语言。
文本摘要自动生成文本的简洁摘要。
问答系统根据用户问题从知识库或文档中寻找答案。
情感分析判断文本中表达的情感倾向。
文本分类将文本归入预定义的类别。

# ============ 计算机视觉 ============
计算机视觉使机器能够从图像和视频中提取有意义的信息。
图像分类是计算机视觉的基础任务，将图像归入预定义类别。
目标检测在图像中定位并识别多个对象。
语义分割为图像中的每个像素分配类别标签。
实例分割区分图像中的不同实例。
全景分割结合了语义分割和实例分割。
关键点检测定位图像中人体或物体的关键点。
光流估计计算图像中像素的运动轨迹。
图像生成是计算机视觉的重要应用，包括GAN和扩散模型。
视觉_transformer在图像识别任务中取得了优异表现。

# ============ 模型架构与训练技术 ============
神经网络的参数量决定了模型的容量和表达能力。
训练大模型需要大量的计算资源和高质量的训练数据。
模型压缩技术包括剪枝、量化和知识蒸馏。
模型量化将浮点参数转换为低精度整数，减少内存占用。
知识蒸馏通过教师模型指导学生模型学习。
混合精度训练通过半精度浮点数加速训练。
梯度累积通过多次前向传播模拟更大的批次大小。
分布式训练将训练任务分散到多个设备上。
数据并行将数据分片到不同设备，模型并行将模型分片。
ZeRO优化通过分片优化器状态、梯度和参数降低内存占用。

学习率调度对训练效果有重要影响。
余弦退火是一种常用的学习率调度方法。
Warmup在训练初期逐步增加学习率，稳定训练。
梯度裁剪防止梯度爆炸问题。
权重衰减通过L2正则化防止过拟合。
AdamW优化器结合了自适应学习率和权重衰减。
动量法加速梯度下降的收敛。
二阶优化方法利用二阶导数信息，但计算成本高。

最大似然估计是参数估计的常用方法。
信息论中的熵、交叉熵和KL散度是机器学习的重要概念。
梯度下降是优化神经网络参数的基本算法。
反向传播算法用于计算神经网络的梯度，是深度学习的基础。
链式法则使得复杂函数的梯度计算成为可能。
凸优化理论为简单模型的优化提供了理论保证。
非凸优化是深度学习面临的主要挑战。

# ============ 模型评估与指标 ============

# ============ 长文本理解训练 ============
人工智能的发展历程可以分为几个重要阶段。早期的符号主义AI基于逻辑推理，试图用规则和符号模拟人类思维。随后的连接主义AI模仿生物神经网络，开创了神经网络的研究。现代的深度学习通过多层网络和大数据，在视觉、语言、语音等领域取得突破。未来的发展方向包括通用人工智能、具身智能和神经符号系统的融合。

机器学习的核心思想是从数据中学习规律。监督学习使用带标签的数据，让模型学习从输入到输出的映射。无监督学习从无标签数据中发现隐藏的模式。强化学习通过与环境交互，学习最优的决策策略。每种方法都有其适用的场景，实际应用中常常结合使用多种方法。

深度学习成功的关键在于其强大的特征学习能力。传统的机器学习方法需要人工设计特征，而深度学习通过多层网络自动学习层次化的特征表示。浅层网络学习简单的边缘和纹理特征，深层网络学习复杂的语义概念。这种端到端的学习方式大大简化了模型开发流程。

Transformer架构的革命性在于完全摒弃了循环结构，仅依赖注意力机制处理序列。自注意力让序列中的每个位置都能直接关注其他所有位置，有效解决了长距离依赖问题。多头注意力并行地执行多个注意力计算，从不同子空间捕捉信息。位置编码为模型提供了序列的顺序信息。

大语言模型的训练通常包括预训练和微调两个阶段。预训练阶段使用海量无标注文本，通过预测下一个token学习语言的统计规律。微调阶段使用有标注数据，让模型适应特定任务。指令微调和人类反馈强化学习进一步提升了模型的指令遵循能力和对齐人类价值观。

StellarAI作为一个轻量级多模态模型，展示了在资源受限环境下构建AI系统的可能性。它采用紧凑的模型架构，通过共享参数和高效设计在保持性能的同时降低计算需求。其支持文本和图像的多模态输入，能够执行对话、问答、图像理解等任务。MIT许可证使其可以自由用于商业项目。

开源AI模型的发展推动了技术的民主化进程。任何人都可以访问、使用、修改和分发开源模型，这降低了AI应用的门槛，促进了创新。开源社区汇聚了全球开发者的智慧，加速了技术迭代。开源模型的可商用特性为创业公司和个人开发者提供了低成本进入AI领域的机会。

# ============ 编程代码示例 ============
Python变量赋值使用等号完成，例如 x = 10 将整数10赋给变量x，解释器会自动推断类型，无需提前声明。
Python支持多种内置数据类型，包括整数int、浮点数float、字符串str、布尔bool和复数complex，可用type()函数查看变量类型。
列表list是可变有序序列，用方括号定义如 nums = [1, 2, 3]，支持append、pop、sort等方法以及索引切片操作。
元组tuple是不可变序列，用圆括号定义如 point = (3, 4)，一旦创建就不能修改，适合存储固定的坐标或配置。
字典dict通过键值对存储数据，用花括号定义如 user = {"name": "李四", "age": 30}，根据键查找值的效率接近O(1)。
集合set存储唯一不重复元素，用花括号或set()定义如 s = {1, 2, 3}，支持并集交集差集等集合运算。
条件语句使用if-elif-else结构，根据条件真假分支执行不同代码块，Python依靠缩进而非花括号界定代码层次。
for循环遍历可迭代对象，例如 for item in [1, 2, 3]: print(item) 会依次输出列表中的每个元素。
while循环在条件为真时重复执行代码块，例如 n = 0; while n < 5: n += 1，必须确保条件最终变为假以避免死循环。
列表推导式提供简洁的列表生成方式，例如 squares = [x*x for x in range(10)] 一行代码生成0到9的平方数列表。
函数用def关键字定义，例如 def add(a, b): return a + b，调用时传入参数add(3, 5)即可获得返回值8。
函数参数可以设置默认值，例如 def greet(name, msg="你好"): print(msg, name)，省略msg时自动使用默认值。
lambda匿名函数用于简单的一次性操作，例如 square = lambda x: x*x，常与map、filter等高阶函数配合使用。
类用class关键字定义，例如 class Dog: def __init__(self, name): self.name = name，通过Dog("旺财")实例化创建对象。
类的继承让子类获得父类的属性和方法，例如 class Cat(Animal): 让Cat继承Animal的全部特性并可扩展新功能。
异常处理使用try-except结构，例如 try: result = 10 / 0 except ZeroDivisionError: print("除零错误") 捕获特定异常。
文件读取推荐使用with语句自动管理资源，例如 with open("data.txt", "r") as f: content = f.read() 读取全部内容。
文件写入模式有w覆盖写入、a追加写入、x独占创建，例如 with open("log.txt", "a") as f: f.write("新日志\n") 追加内容。
字符串常用方法包括split分割、join连接、strip去除空白、replace替换子串和upper转大写等，链式调用提高效率。
enumerate函数同时获取索引和元素，例如 for i, val in enumerate(["a", "b"]): print(i, val) 同时拿到位置和值。
zip函数并行遍历多个序列，例如 for a, b in zip([1, 2], [3, 4]): print(a, b) 将对应位置的元素配对处理。
冒泡排序通过相邻元素比较交换实现排序，伪代码：for i in range(n): for j in range(n-i-1): if arr[j]>arr[j+1]: swap(arr[j],arr[j+1])。
冒泡排序时间复杂度为O(n²)，空间复杂度O(1)，是稳定的排序算法，适合小规模数据排序或教学演示使用。
选择排序每轮选出最小元素放到前端，伪代码：for i in range(n): min_idx=i; for j in range(i+1,n): if arr[j]<arr[min_idx]: min_idx=j; swap。
选择排序时间复杂度O(n²)，是不稳定排序，交换次数少于冒泡排序但比较次数相同，实现简单直观。
插入排序将当前元素插入已排序部分的正确位置，类似整理扑克牌的过程，对小规模或近似有序数据非常高效。
插入排序平均时间复杂度O(n²)，最好情况O(n)，是稳定的原地排序算法，常作为高级排序的子过程使用。
二分查找要求数组有序，每次比较中间元素缩小一半范围，伪代码：while left<=right: mid=(left+right)//2; if arr[mid]==target: return mid。
二分查找时间复杂度O(log n)，远优于线性查找的O(n)，是查找有序数据的高效算法，但前提是数据必须有序。
斐波那契数列递归实现：def fib(n): return n if n < 2 else fib(n-1) + fib(n-2)，代码简洁但存在大量重复计算。
斐波那契数列迭代实现效率更高，使用两个变量滚动计算 a, b = b, a+b，时间复杂度O(n)，空间复杂度O(1)。
快速排序采用分治思想，选取基准值pivot将数组分为小于和大于两部分递归排序，平均时间复杂度O(n log n)。
快速排序伪代码：def quicksort(arr): if len(arr)<=1: return arr; pivot=arr[0]; return quicksort([x for x in arr[1:] if x<pivot])+[pivot]+quicksort([x for x in arr[1:] if x>=pivot])。
归并排序也是分治算法，先将数组对半分割直到单个元素，再有序合并两个子数组，时间复杂度稳定为O(n log n)。
归并排序需要O(n)额外空间，是稳定排序，适合链表排序和外部排序场景，最坏情况性能仍为O(n log n)。
线性查找逐个比较元素，伪代码：for i in range(n): if arr[i] == target: return i，时间复杂度O(n)，不要求数据有序。
栈是后进先出LIFO结构，可用列表实现，append入栈pop出栈，常用于函数调用管理和括号匹配检查。
队列是先进先出FIFO结构，推荐用collections.deque实现，append入队popleft出队，两端操作均为O(1)。
哈希表通过哈希函数映射键到存储位置，Python的dict就是哈希表实现，查找和插入平均时间复杂度O(1)。
递归函数调用自身解决规模更小的子问题，必须有终止条件防止无限递归，例如阶乘def factorial(n): return 1 if n<=1 else n*factorial(n-1)。
递归需注意栈溢出风险，深度过大时可改用迭代实现，Python默认递归深度限制约为1000层，可用sys.setrecursionlimit调整。
面向对象三大特性是封装、继承和多态，封装隐藏内部实现细节，继承复用已有代码，多态允许同一接口不同实现。
魔术方法如__init__构造初始化、__str__字符串表示、__len__长度、__eq__相等比较，让自定义类支持Python内置操作。
装饰器是修改函数行为的语法糖，例如 @timer 可在不改变原函数代码的情况下添加计时功能，本质是接收函数返回函数的高阶函数。
生成器使用yield关键字惰性产生值，例如 def counter(): n=0; while True: n+=1; yield n，按需生成节省内存适合大数据流。
map函数将函数应用到每个元素，例如 list(map(str, [1, 2, 3])) 得到 ['1', '2', '3']，返回迭代器需用list转换。
filter函数筛选满足条件的元素，例如 list(filter(lambda x: x > 0, [-1, 2, 3, -4])) 得到 [2, 3] 保留正数。
sorted函数返回排序后的新列表，支持key参数自定义排序规则，例如 sorted(students, key=lambda s: s['age']) 按年龄排序。

池塘里的睡莲面积每天翻倍，30天长满整个池塘，那么长满一半池塘需要29天，因为每天翻倍所以前一天正好是一半。
五个苹果分给三个小朋友，每人至少一个，有多少种分法？这是把相同物品分给不同组的组合问题，答案是C(4,2)=6种。

三个盒子分别贴着苹果、橘子、混合的标签且全部贴错，从混合标签的盒子中摸出一个水果即可确定所有盒子内容。

因果关系推理中，相关不等于因果，冰淇淋销量和溺水人数同时增加是因为夏天高温这一共同原因，并非前者导致后者。

逻辑推理中，否定前件是谬误：如果下雨就带伞，没下雨，不能推出没带伞，因为可能因为其他原因带伞。

归纳推理从特殊事例总结一般规律，例如观察到多只天鹅都是白色，归纳出天鹅都是白色的，但可能被黑天鹅证伪。
演绎推理从一般原理推出特殊结论，前提为真则结论必然为真，例如所有人会死，苏格拉底是人，所以苏格拉底会死。
假设A说B在说谎，B说C在说谎，C说A和B都在说谎，若只有一人说真话，则B说真话，A和C在说谎。
数学推理：若一个数的各位数字之和能被3整除，则该数能被3整除，例如123各位和为6，所以123能被3整除。
排列组合推理：从5人中选3人排队，有5×4×3=60种排法，这是排列问题考虑顺序；若只选3人不排队则有C(5,3)=10种。
逻辑等价：不所有都等同于有些不，并非所有人都喜欢音乐等价于有些人不喜欢音乐，这是量词否定的德摩根律。
条件推理：如果土壤湿润且阳光充足，则种子会发芽。现在种子没发芽，可以推出土壤不湿润或阳光不充足至少一个不满足。

圆的周长公式C=2πr，面积公式S=πr²，其中r是半径，π是圆周率约等于3.14159，是无理数。
三角函数包括正弦sin、余弦cos和正切tan，定义于直角三角形边长之比，在周期现象和波动中有广泛应用。
对数是指数的逆运算，若a^x=N则log以a为底N的对数等于x，常用对数以10为底，自然对数以e为底。
导数是函数在某点的瞬时变化率，几何意义是切线斜率，f'(x)=lim(Δx→0)[f(x+Δx)-f(x)]/Δx。
积分是求函数图像下方面积的运算，定积分表示区间内累积量，不定积分是求原函数，二者由牛顿莱布尼茨公式联系。
极限是微积分的基础概念，描述函数值在自变量趋于某值时的趋势，lim(x→a)f(x)=L表示x趋近a时f(x)趋近L。
概率是描述随机事件发生可能性的数值，取值0到1之间，必然事件概率为1不可能事件概率为0。
条件概率P(A|B)表示在事件B已发生条件下事件A发生的概率，公式P(A|B)=P(A∩B)/P(B)。
贝叶斯定理描述了在获得新证据后更新概率的方法，公式P(A|B)=P(B|A)P(A)/P(B)，是统计推断的重要工具。
期望是随机变量取值的加权平均，反映随机变量的平均水平，离散型期望E(X)=Σxi·P(xi)。
方差度量随机变量偏离期望的程度，方差越大波动越剧烈，标准差是方差的平方根与原数据同量纲。
正态分布是重要的连续型概率分布，呈钟形曲线对称分布，由均值μ和标准差σ决定，自然界许多现象近似服从正态分布。
矩阵是按行列排列的数表，矩阵加减要求同型对应元素运算，乘法要求前矩阵列数等于后矩阵行数。
行列式是方阵对应的标量值，二阶行列式|a b; c d|=ad-bc，可用于判断矩阵是否可逆和解线性方程组。
向量是具有大小和方向的量，向量加法遵循平行四边形法则，点积a·b=|a||b|cosθ反映方向关系。
数列是按一定顺序排列的数，等差数列相邻项差为常数d，通项an=a1+(n-1)d，前n项和Sn=na1+n(n-1)d/2。
等比数列相邻项比为常数q，通项an=a1·q^(n-1)，前n项和Sn=a1(1-q^n)/(1-q)当q不等于1时。
排列数A(n,m)=n!/(n-m)!表示从n个不同元素取m个的排列数，组合数C(n,m)=n!/(m!(n-m)!)表示组合数不考虑顺序。
阶乘n!=1×2×3×…×n，规定0!=1，阶乘增长极快，20!已超过2乘以10的18次方。
组合数学的鸽巢原理说明若将n+1个物体放入n个盒子，至少有一个盒子有不少于两个物体，简单却应用广泛。
微积分基本定理即牛顿莱布尼茨公式，将微分和积分联系起来，∫(a到b)f(x)dx=F(b)-F(a)，F是f的原函数。
泰勒展开用多项式逼近函数，f(x)=f(a)+f'(a)(x-a)+f''(a)(x-a)²/2!+…，在近似计算和分析中非常重要。
复数由实部和虚部组成a+bi，其中i²=-1，复数在电学和量子力学中有重要应用，欧拉公式e^(iπ)+1=0极其优美。
黄金分割比φ约等于0.618，满足φ=(1+√5)/2，广泛存在于自然界和艺术建筑中，被认为是最美的比例。
斐波那契数列1、1、2、3、5、8、13…前后项之比趋于黄金分割比，在自然界花瓣数和螺旋线中常见。
三角形的内角和等于180度，任意多边形内角和等于(n-2)×180度，n为边数，外角和恒为360度。
相似三角形对应边成比例对应角相等，全等三角形则对应边和角完全相等，有SSS、SAS、ASA、AAS等判定方法。
线性方程组ax+by=c的解法有代入法和消元法，几何上表示直线的交点，二元一次方程组可用行列式或矩阵求解。
绝对值|x|表示数轴上点到原点的距离，非负数，满足|a|+|b|≥|a+b|三角不等式，是数学分析的基本工具。
函数的定义域是自变量允许取值的集合，值域是因变量对应的集合，函数关系描述了输入到输出的唯一映射。
指数函数y=a^x(a>0且a≠1)单调递增或递减，对数函数是其反函数，二者图像关于直线y=x对称。
三角形的面积公式S=底×高÷2，海伦公式S=√(p(p-a)(p-b)(p-c))其中p为半周长，适用于已知三边求面积。
统计中的中位数是数据排序后中间的值，众数是出现次数最多的值，均值是算术平均，三者反映数据的集中趋势。
二项式定理(a+b)^n=ΣC(n,k)a^(n-k)b^k，杨辉三角直观展示二项式系数，第n行系数对应(a+b)^n的展开。
圆锥曲线包括椭圆双曲线和抛物线，椭圆两焦点距离和为常数，双曲线距离差为常数，抛物线是到焦点和准线等距的点轨迹。
欧拉公式V-E+F=2对任意凸多面体成立，其中V是顶点数E是棱数F是面数，是拓扑学的基本定理之一。

请列举常见的设计模式：单例模式保证一个实例、工厂模式封装对象创建、观察者模式发布订阅事件、策略模式封装可互换算法。
请解释什么是负载均衡：负载均衡将网络请求分发到多台服务器上，提高系统吞吐量和可用性，常见算法有轮询、加权轮询和最少连接。
请描述HTTPS的工作原理：HTTPS在HTTP下加入SSL/TLS层，客户端验证服务器证书建立加密通道，传输内容加密保证机密性和完整性。
请对比瀑布模型和敏捷开发：瀑布模型顺序完成各阶段文档完善但灵活性差，敏捷开发迭代增量快速响应变化强调沟通协作。
请说明什么是缓存及其作用：缓存是临时存储高频访问数据的技术，减少数据库或远程访问压力，显著提升读取速度，常用Redis Memcached。
请解释什么是容器编排：容器编排自动管理容器的部署扩缩容和故障恢复，Kubernetes是最流行的编排平台，实现应用的高可用运行。
请总结DevOps的核心理念：DevOps打破开发和运维的壁垒，通过自动化CI/CD流水线实现持续交付，强调协作监控和快速反馈迭代。
